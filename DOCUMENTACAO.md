# Documentação do Projeto AgroConnect

## Objetivo
O AgroConnect é um projeto de software voltado à gestão de operações do agronegócio.

## Funcionalidades
- Cadastro de propriedades rurais.
- Consulta de produção agrícola.
- Organização de informações do agronegócio.

## Tecnologias utilizadas
- Python
- Git
- GitHub

## Controle de versão
O Git é utilizado para acompanhar as alterações realizadas nos arquivos do projeto, enquanto o GitHub permite armazenar e compartilhar o código.
